# Code of Conduct

## Our standard

Shamaran is an open project where contributors should be able to participate
without harassment or discrimination. Be respectful, discuss ideas and code rather
than people, accept constructive feedback, and assume good intent while asking for
clarification.

Unacceptable behavior includes harassment, threats, discriminatory language,
deliberate intimidation, publishing another person's private information, and
repeated disruption of project discussions.

## Scope

This standard applies in the repository, issue tracker, pull requests, releases,
and other spaces where a person is representing the Shamaran project.

## Enforcement

Report conduct concerns privately to the maintainer through the contact method on
[Ashkan Allahveisi's GitHub profile](https://github.com/ashkanWaisi). Include links
or screenshots when possible. Reports will be reviewed in confidence. The
maintainer may edit or remove content, issue a warning, temporarily restrict
participation, or permanently ban a participant when necessary to protect the
community.

Project decisions are made by the maintainer, **Ashkan Allahveisi**.
